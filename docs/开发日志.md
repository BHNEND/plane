# 开发日志

## 2026-08-31

- 为 `BHNEND/plane` 增加 GitHub Actions 自动部署工作流：`.github/workflows/deploy.yml`。
- 工作流使用 `DEPLOY_HOST`、`DEPLOY_PORT`、`DEPLOY_USER`、`DEPLOY_PATH` 和 `DEPLOY_SSH_KEY` 连接服务器。
- 使用官方 Plane 社区版 `v1.4.2` Compose 清单。
- 保留服务器部署目录中的 `.env`，部署前检查域名、版本和端口配置，不上传或打印敏感值。
- Plane 内部代理只绑定服务器本机的 `127.0.0.1:13200` 和 `127.0.0.1:13201`，由宝塔在容器启动后负责域名和 SSL 反向代理。
- 当前服务器部署目录：`/www/wwwroot/Plane`；域名：`plane.lklk.ai`。
